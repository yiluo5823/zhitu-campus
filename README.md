# 知途：高校问题悬赏与知识协作平台

知途面向高校学生，把付费问答、精选论坛、问题知识库和回答者信誉档案放在同一个产品中。用户既可以发布带附件的悬赏问题，也可以先在知识库中连续追问、自助梳理解决路径。

线上演示：https://hilarious-nougat-97963d.netlify.app/

## 核心功能

- 问题悬赏：10–1000 知点连续定价，支持学科分类和多附件上传。
- 付费回答：回答者可设置 0–500 知点解锁价，展示公开摘要、完整度与准确度。
- 双向议价：提问者可以还价，回答者可以接受或拒绝，再按协商价格解锁。
- 问题知识库：通过 Netlify AI Gateway 调用 OpenAI 模型，支持连续追问、开启新问题、相关方法卡和行动流程。
- 精选论坛：行业新闻、科研工具和校园讨论；普通用户内容先审核后公开。
- 权威档案：教育背景、认证状态、提问战绩、回答战绩和获赏次数。
- 像素 UI：支持主色、颗粒、密度和发光强度个性化调整，适配 PC 与手机端。

## 技术结构

- 前端：原生 HTML、CSS、JavaScript。
- 身份认证：Netlify Identity。
- 服务端：Netlify Functions。
- 数据和附件：Netlify Blobs。
- AI 问答：OpenAI Responses API，通过 Netlify AI Gateway 调用。
- 托管：GitHub + Netlify 自动部署。

主要文件：

- `index.html`：页面结构和主要交互入口。
- `styles.css`：像素风基础样式。
- `modules-v2.css`：论坛、知识库、排行榜和议价模块样式。
- `app.js`：浏览器端状态、交互、身份和 API 调用。
- `netlify/functions/api.mjs`：问题、回答、议价、论坛、附件、档案和 AI 问答接口。

## 本地运行

```bash
pnpm install
netlify dev
```

必须通过 `netlify dev` 启动，才能在本地使用 Identity、Blobs 和 AI Gateway 等 Netlify 能力。

## Netlify 配置

1. 开启 Netlify Identity，并选择开放注册或邀请注册。
2. 如要求邮箱验证，用户必须点击确认邮件后才能登录。
3. 给运营账号添加 `admin` 或 `moderator` 角色。
4. 保持 GitHub 主分支与 Netlify Production deploy 连接。
5. AI Gateway 在 Netlify 的 Credit-based plans 中可自动提供模型调用环境变量；也可以自行配置 `OPENAI_API_KEY`。
6. 可选环境变量 `OPENAI_MODEL` 用于覆盖默认模型；未设置时使用 `gpt-5-mini`。

## 内容与支付边界

- 当前“知点”是站内演示账本，不等同于真实货币。
- 接入人民币支付前，需要补充支付渠道、退款、发票、未成年人保护和平台服务协议。
- AI 回答可能出错，涉及论文引用、医疗、法律、财务等内容必须核验原始来源。
- 普通用户论坛内容默认进入审核队列，避免垃圾信息直接公开。

## 发布流程

推送 GitHub 主分支后，Netlify 会自动构建并更新线上演示链接。部署后建议检查：

- 首页与移动端导航；
- Identity 注册、邮箱确认与登录；
- 悬赏发布、回答、议价和解锁；
- 附件访问权限；
- 知识库连续追问与新对话；
- 论坛审核状态和个人战绩。
